# v0.1.2

Generic handoff port fix for macOS NodePort consumers.

## Change

Controller-owned native-Pod handoffs now include:

```text
storage.k8s-darwin.dev/nfs-port
```

The value is `EndpointStatus.NFSPort`: the allocated NodePort for a NodePort
endpoint, or the Service port for ClusterIP/LoadBalancer endpoints. Stale
handoff cleanup removes it with the other controller-owned annotations. This
allows maclet to construct canonical NFS options without inferring the NFS
port.

docker.io/initialed85/longhorn-nfs-gateway@sha256:f5804c26859427a1c560381da2bc95623761c0518f257fa2b79f1626a3f740c9
