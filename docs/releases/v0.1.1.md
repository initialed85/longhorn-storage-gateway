## RWX bootstrap behavior

For an existing `ReadWriteMany` PVC, the controller first creates an owned
Recreate Deployment that mounts the PVC and sleeps. This triggers CSI and
Longhorn share-manager creation. Only after the share-manager Service has a
Ready EndpointSlice does the controller create the FSAL_PROXY_V4 helper.

If the share-manager endpoint disappears, proxy resources are cleaned while the
bootstrap consumer remains available to trigger recovery. Once the endpoint
returns, the proxy is recreated and endpoint status returns to Ready. Finalizer
cleanup removes both bootstrap and proxy resources without deleting the PVC/PV.
